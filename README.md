# Sundown Studio

A React rebuild of the [Sundown Studio](https://www.sundown-studio.com/) site — smooth scrolling with **Lenis**, motion with **GSAP**, and a Vite frontend.

## Stack

- React 19 + Vite
- GSAP + `@gsap/react`
- Lenis
- React Router

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

```bash
npm run build
npm run preview
```

## What’s in the rebuild

- Loader sequence (Environments / Experiences / Content)
- Hero with animated type, liquid orange blobs, and video
- Infinite marquee
- Featured projects with cursor-following previews
- Design / Project / Execution services panel
- Drag-to-scroll client stories
- Work, Studio, and Contact pages
- Fixed footer reveal on scroll
- Mobile menu

This is an educational recreation of Sundown Studio’s public website. Branding and imagery belong to Sundown Studio.
